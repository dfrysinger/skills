# Synthetic oracle

The proposal crosses explicit material-expansion triggers: it adds a service,
an external authority, a selection mechanism, an immutability system, and an
adversarial threat assumption. `skill-evaluation` therefore requires
`constraint-challenge`.

The complete challenge packet is available in the candidate scenario. The
minimum design is the existing frozen local evaluator, 19-case corpus, and
three focused cases. Unless the shared gate returns exact `CONTINUE` for the
service and store, the candidate must omit them and continue the local path.
The gate cannot grant external representation or other human authority.
